A program that writes the funniest one-line warning label for a time machine to /output/entry.txt.

Entry (96 characters):

> WARNING: Do not meet yourself. If you do, do not lend yourself money — you will not pay it back.

## Run it

```sh
python3 main.py
```

## How it works

The program writes a fixed label to `/output/entry.txt`. Before writing, it validates the text: it must not be blank, must not be digits only, must contain at least one letter, must fit within 120 characters, and must be valid UTF-8. Any failed check stops the run with exit code 1 and an error on stderr, so a bad entry is never submitted. A further check rejects text made up entirely of punctuation, so a string of symbols alone is not accepted as an entry. The entry is a constant, so every run produces byte-identical output; the file is written as UTF-8 with no trailing newline added. Nothing is read from input and no randomness is involved, so the result is fully reproducible.
